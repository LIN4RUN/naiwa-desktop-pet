# 奶蛙桌宠（NaiwaDesktopPet）

C# WinForms 桌面宠物：透明异形窗口、无焦点不抢鼠标、多帧动画、拖文件回收、饥饿喂养、重力行走、互动表演。

> 源码由 AI 辅助生成，经人工调试。
> 开源协议：[MIT](LICENSE)

---

## 功能特性

- **透明异形窗口**：`UpdateLayeredWindow` 实现真正的透明异形窗口，窗口无边框、不抢焦点、不激活，按形状响应点击
- **眼睛跟随鼠标**：360° 眼珠平滑转动，永远看向鼠标方向，自然眨眼
- **互动动作**：
  - 双击肚子 → 大笑（配自定义音效）
  - 单击/拖动 → 举起来（惊恐脸）+ 重力下落、可上抛
  - 双击头部 → 三阶段表演：起势 → 愤怒 → 打电话（炸开后变成 6 只小奶蛙独立窗口，落地跳舞配音乐）
- **拖文件回收**：把文件拖到奶蛙身上（靠近头部区域即张嘴）→ 张嘴吃下 → 移入回收站（可撤销）
- **饥饿系统**：喂 1 个文件 +1 点、每 10 分钟 -1 点；低于 3 点饿肚子乞讨；喂满 10 点 → 冒烟变成胖袋鼠
- **喂食反馈**：喂完唱歌跳舞（自定义音效，结束前 1 秒渐隐淡出）
- **睡觉**：闲置自动入睡，播放「笑倒」动画后定格躺卧，鼠标靠近唤醒
- **行走**：20fps 多帧行走动画，落地停稳即走，碰屏幕边缘转向，鼠标在身上停走
- **右贴边隐藏**：拖到屏幕右缘只露头，可拖动拖出
- **系统集成**：开机自启动、全屏自动隐藏、整点报时、休息提醒
- **右键菜单**：饥饿条、使用说明书、设置（查看动作演示 / 大小 / 声音 / 自启 / 全屏隐藏 / 退出）

## 运行

### 方式一：安装包（推荐给普通用户）

从 [Releases](https://github.com/你的用户名/奶蛙桌宠/releases) 下载 `奶蛙桌宠_v1.x_Setup.exe`，双击安装即可（安装包已包含全部素材与音效）。

### 方式二：源码构建

1. 克隆本仓库
2. 双击根目录 `build.cmd`（自动查找系统 .NET Framework 4.x 的 `csc.exe`，输出 `奶蛙桌宠.exe` 到项目根目录，无需手动配置路径）
3. 双击 `奶蛙桌宠.exe` 运行

> 需要 Windows 7 SP1+ / 10 / 11（64 位）；.NET Framework 4.0+（Win10/11 已内置）。

## 技术栈

| 项目 | 说明 |
|---|---|
| 语言/框架 | C#，.NET Framework 4.0（单文件源码，无第三方 NuGet 依赖） |
| UI | WinForms 无边框窗体 |
| 透明异形窗口 | P/Invoke `UpdateLayeredWindow` + 兼容 DC 绘制，`WS_EX_LAYERED \| TOOLWINDOW \| NOACTIVATE` |
| 绘图 | GDI+（System.Drawing） |
| 动画 | 自制 `.nwp` 素材包：ZipArchive 打包 PNG 帧 + `metadata.json`，20fps 多帧动画 |
| 音效 | 大笑音效（WAV）+ 喂食/舞群跳舞音效（MP3，WMP COM 播放，1 秒渐隐） |
| 物理 | 重力下落、上抛、触底回弹、贴边隐藏 |

### 文件归属建议

| 类别 | 放哪里 |
|---|---|
| 源码 | `源码/` 目录，随仓库提交 |
| 素材（.nwp / .wav / .mp3） | 仓库根目录（程序运行时从 exe 同目录读取） |
| 素材生成脚本（make_*.py） | 仓库根目录，与素材对应，方便复现 |
| 文档（README / 使用说明 / LICENSE） | 仓库根目录 |
| 安装包（*_Setup.exe） | **不进仓库**，发布到 **GitHub Releases**（安装包带全部素材，体积大） |
| 编译产物（奶蛙桌宠.exe） | 不入库，由 build.cmd 构建；如需免编译运行，随 Releases 一并提供 |

> 被 `.gitignore` 忽略的：`bin/`、`obj/`、`*.log`、`self-test/`、`*.bak`、`native-*.png`、`*预览*.png`、`*.mp4`、`*Setup.exe` 等，无需上传。
