奶蛙桌宠 v2.5 使用说明书

一、日常互动（鼠标操作）
1.1 拖动与重力
按住左键拖动奶蛙：随意移动位置，它会摆出惊恐的表情
松手后受重力自然下落，落地站稳后自己走两步；碰到屏幕边缘自动转向
快速往上甩（拖住后猛地向上移动再松手）：把它抛上天，它会惊恐地飞上去再掉下来
      v2.5 新增：摔下来之后它会哭一场（配哭泣音效 cry.wav）
奶蛙走路时鼠标放到它身上，它会停下不走了
1.2 右贴边隐藏
把奶蛙拖到屏幕最右边缘松手：它斜靠着右缘「缩头」，只露出一颗头；再拖一下即可拖出来
贴边隐藏时除了拖动，不会触发其他任何动作
1.3 点击
单击肚子：肚子凹一下再弹起（约 1 秒）
双击肚子：捧腹大笑并播放笑声；再次单击可停止
双击头部（头部全部区域）：三阶段表演（起势 → 愤怒 → 打电话，炸开 6 只小奶蛙跳舞）
1.4 眼睛与睡觉
眼睛会一直看向鼠标的方向，即使鼠标不在它身上
长时间没人理它，它会入睡：趴下、播放「笑倒」动画后定格躺卧，鼠标靠近即醒
1.5 待机小动作（v2.5 新增）
放着不管的时候，它偶尔会自己动两下：小动作、转手舞
想看效果：右键 → 设置 → 查看动作 → 小动作 / 转手舞

二、喂食
把文件或文件夹从桌面 / 资源管理器拖到奶蛙身上：
拖到它身上悬停：奶蛙张开嘴等你放下
放下：吃下并跳舞庆祝（带音效）
拖过来却没放下、把文件拖走了：奶蛙露出沮丧委屈的表情约 1 秒
跳舞庆祝时再拖文件过来：它会停下舞步，重新张嘴等你

三、饥饿系统
　　　奶蛙有饥饿条，一共 10 点：
每喂 1 个文件，饥饿 +1（最多 10 点）
每过 10 分钟自动 -1 点
饥饿低于 3 点时，每次扣点它都会跪地乞讨，头顶显示「我好饿…」，持续 10 秒——该喂它了
想看饥饿值：右键奶蛙，菜单第一行就是「饥饿 ▓▓▓ n/10」
喂满 10 点后再喂：奶蛙张嘴吃下（只播回收动画的张嘴、吞咽段），冒烟，然后撑成一只胖袋鼠，并弹出气泡「我的肚子真是肥嘟嘟的」

四、右键菜单（托盘图标右键同样是这个菜单）
　　　在奶蛙身上点右键打开菜单；v2.5 起任务栏右下角还有个小图标，右键同效、双击把奶蛙叫回来：
饥饿 ▓▓▓ n/10：当前饥饿值（只显示，不能点）
使用说明书：打开本文档
设置 → 查看动作：演示各动作（大笑 / 小动作 / 转手舞 / 哭泣（上抛后）/ 行走 / 起势 / 愤怒 / 打电话·炸开舞群 / 喂食庆祝舞蹈 / 饥饿乞讨 / 吃饱变袋鼠 / 睡觉）
设置 → 大小：8 档尺寸（50%～150%），另有「放大 5% / 缩小 5%」微调
设置 → 声音：开 / 关全部音效（大笑、哭泣、跳舞）
设置 → 音量：(v2.5 新增) 拖动滑条调 0%～100%，会立即生效
设置 → 开机自启动：登录 Windows 后自动运行
设置 → 全屏时自动隐藏：视频、游戏等全屏时奶蛙自动躲起来，退出全屏后恢复
设置 → 退出奶蛙：关闭桌宠
　　　提示：菜单打开后，鼠标 3 秒内没有落到菜单上会自动收起；点击菜单以外的任何地方也会立即收起。

六、常见问题
Q：双击没反应 / 提示「缺少动作素材」？
A：说明素材文件没放全或名字被改了，请把下载的压缩包完整解压，exe 与所有 .nwp、.wav、.mp3 放在同一个文件夹。
Q：没有声音？
A：先看右键 → 设置 → 声音是否开着、音量是否拉到 0；音效依赖 Windows Media Player 组件（Win10/11 一般自带）。
Q：怎么彻底卸载？
A：右键 → 设置 → 退出奶蛙，然后删掉整个文件夹；如开过自启动，再在「设置 → 开机自启动」里关一次（或删除注册表 Run 项 NaiwaDesktopPet）。
